# Identidade oficial

O logo fornecido está em `logo.webp`. O build procura `logo.webp`, `logo.png`, `logo.jpg`,
`logo.jpeg` ou `logo.svg`, nessa ordem, e gera `catalog.json` automaticamente. O catálogo
e o logo são armazenados no cache offline.

Não altere o desenho, texto ou proporções da marca. O arquivo atual foi apenas convertido
para WebP e recortado nas margens escuras vazias; veja `docs/IMAGES.md`.
